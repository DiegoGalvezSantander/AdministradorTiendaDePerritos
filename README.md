# AdministradorTiendaDePerritos

## 🔗 Repositorio
https://github.com/DiegoGalvezSantander/AdministradorTiendaDePerritos

## 📋 Descripción
Panel de administración del proyecto TiendaDeMascotas. Permite gestionar productos, usuarios y órdenes mediante CRUD completo con roles de Administrador, Vendedor y Cliente.

## 🛠️ Tecnologías
- HTML5 semántico
- CSS3 (externo, variables, responsive)
- JavaScript ES6 (validaciones, localStorage)

## 🚀 Cómo ejecutar
1. Abrir `IniciarSesion.html` en el navegador.
2. Ingresar con: `admin@duoc.cl` / `1234`
3. Redirige automáticamente al panel de administración.
